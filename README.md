# Student Management System

A simple Java console application for registering students and recording and viewing their marks.

## Features

- Teacher login
- Register multiple students with a name, registration number, subject, and class
- Record marks between 0 and 100
- View registered students and their marks
- Validate numeric input

## Requirements

- Java Development Kit (JDK) installed

## Compile and run

Open a terminal in the project folder and run:

```text
javac StudentManagementSystem.java
java StudentManagementSystem
```

## Login

The application currently uses hard-coded demo credentials in the Java source. Change them in `StudentManagementSystem.java` before using the application beyond a local demonstration. Do not use hard-coded credentials for a real system.
